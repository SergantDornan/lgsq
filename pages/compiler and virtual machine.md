# Как установить джаву
	- Скачиваешь JDK (Java Development KIt)
		- [вот тут](https://www.oracle.com/java/technologies/downloads/) есть архив
- # Чё там есть
	- Там есть в первую очередь две вещи:
	- Компилятор ``javac`` и виртуальная машина ``java``.
	- Первая компилирует код в байт-код. Вторая читает этот байт-код и исполняет.
- # Как скомпилировать
	- Пусть
		- BUILD = [папка куда кладёшь байт-код]
		- FILES = [все файлы с расширением .java которые тебе нужны]
	- ```
	  javac -d $(BUILD) $(FILES)
	  ```
	- На выходе получаются файлы с расширением ``.class``
- # Как запустить
	- Пусть
	- PACKAGE = [пакет, т.е. неймспейс, в котором лежит мейн класс]
		- пакет объявляется в начале файла: ``package mypack;``
	- MAIN_CLASS = [имя класса, в котором объявлена функция мейн]
	- ```
	  java --class-path $(BUILD) $(PACKAGE).$(MAIN_CLASS)
	  ```
