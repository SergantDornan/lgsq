## Введение
	- ### Памятка (для чайников)
		- **Реляционная база данных** - таблица
		- **SQL** - декларативный язык программирования (т.е. непроцедурный, исполняется отдельно вводимыми инструкциями, как командная строка) для управления БД
		- **PostgreSQL** - система управления базами данных (СУБД) на языке SQL (т.е. приложение, исполняющее команды SQL)
		- ### Установка PostgreSQL
			- ```
			  ~$ sudo apt update
			  ~S sudo apt install postgresql postgresql-contrib
			  ```
			- Чтобы проверить, что PostgreSQL запущена, к ней нужно обратиться чере з службу фоновых процессов linux 'serivice':
			- ```
			  ~$ service postgresql status
			  ```
			- Другие опции service можно посмотреть так:
			- ```
			  ~$ service postgresql
			  ```
		- ### Авторизация системного пользователя postgres
			- При установке PostgreSQL в linux создаётся новый пользователь ``postgres`` с рабочей папкой ``/var/lib/postgresql/`` и регистрационной оболочкой (т.е. интерпретатором командной строки) ``/bin/bash``.
			- Просмотреть информацию по пользователям можно в файле ``/etc/passwd``. В ней есть примерно такая строчка:
				- ``postgres:x:129:137:PostgreSQL administrator,,,:/var/lib/postgresql:/bin/bash``
			- Чтобы зайти под этого пользователя, нужно исполнить команду:
			- ```
			  ~$ sudo -i -u postgres
			  ```
			- **флаг ``-i`` означает залогиниться в новую регистрационную оболочку, флаг ``-u postgres`` указывает пользователя.*
			- Делается это с целью безопасности, например, если к серверу СУБД есть удалённый доступ, то человек исполняющий команды не имеет прав доступа на ``root`` или на нашу домашнюю директорию.
